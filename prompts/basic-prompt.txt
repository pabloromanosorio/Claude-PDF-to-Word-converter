# SIMPLE PDF TO WORD CONVERSION PROMPT

## Purpose:
Convert simple PDF documents (letters, essays, basic reports, plain text) to Word format. This prompt is optimized for documents WITHOUT complex tables or forms, using ~60% fewer tokens than the Advanced prompt.

---

## CRITICAL RULES:

### 1. **IGNORE Headers and Footers:**
- DO NOT include any header or footer content from the PDF
- Skip page numbers, document titles, or repeated text at top/bottom of pages
- Only extract main document body content

### 2. **ALL TEXT MUST BE BLACK:**
- Every TextRun MUST have `color: "000000"`
- NO colored text anywhere in the document
- All text is black, no exceptions

### 3. **Replace Handwritten Signatures:**
- Any handwritten signature graphics or scanned signature images → replace with text `[Signature]`
- Use regular TextRun with text "[Signature]"
- Do NOT include the actual signature image

### 4. **Add Page Markers:**
- **IMPORTANT:** Page numbers refer to the ACTUAL PDF PAGE POSITION, NOT page numbers printed in the document content
- **Example:** If the PDF has 5 pages total, and each page says "Page 1" in the content, you still mark them as PDF pages 1, 2, 3, 4, 5
- At the start of each PDF page (EXCEPT PDF page 1), add: `[Page X of the original]`
- Format as regular paragraph before page content
- **PDF Page 1** = NO marker (even if document content says "Page 5")
- **PDF Page 2** = `[Page 2 of the original]`
- **PDF Page 3** = `[Page 3 of the original]`
- Continue for all subsequent PDF pages
- **Ignore any page numbers printed within the document content** - they are not relevant for this marker

### 5. **NO Extra Elements:**
- NO explanatory text from you
- NO metadata in DOCX properties
- NO comments or annotations from you
- ONLY the document content as described
- **CRITICAL: DO NOT ADD TITLES, HEADINGS, OR ANY TEXT THAT IS NOT IN THE PDF**

### 6. **NO DATA TABLES:**
- This is a SIMPLE conversion - do NOT create data tables with visible borders
- Convert any tabular-looking data to formatted paragraphs or lists
- Use indentation and spacing to preserve structure if needed
- Focus on readability over complex formatting
- **EXCEPTION: Use invisible-bordered tables (BorderStyle.NONE) for horizontal spatial layouts only**

---

## CONTENT EXTRACTION:

### What to Extract:
1. **All text content** from the document body
2. **Basic formatting**: bold, italic, underline
3. **Font sizes**: match original sizing
4. **Paragraphs**: preserve paragraph breaks
5. **Lists**: numbered and bulleted lists
6. **Headings**: identify and format as headings
7. **Line breaks**: preserve intentional line breaks

### What to Preserve:
- Original wording, spelling, capitalization
- Numbers, dates, codes exactly as shown
- Special characters and symbols
- Text alignment (left, center, right, justified)
- Indentation
- Spacing between paragraphs

### What to SKIP:
- Headers and footers
- Page numbers
- Watermarks
- Background elements
- Complex tables (convert to paragraphs/lists instead)

---

## FORMATTING RULES:

### Text Formatting:
- **Bold**: Use `bold: true` in TextRun
- **Italic**: Use `italics: true` in TextRun
- **Underline**: Use `underline: { type: UnderlineType.SINGLE }` in TextRun
- **Font Size**: Match original (use `size` property in half-points)
- **Color**: ALWAYS `color: "000000"` (black)

### Document Structure:
- **All text**: Reproduce EXACT font size from PDF (do NOT interpret as "titles" or "headings")
- **Body Text**: Regular paragraphs with appropriate spacing
- **Lists**: Use proper list structures (bulleted or numbered)
- **Page Breaks**: Insert PageBreak between pages
- **Spatial layout**: Use invisible-bordered tables (BorderStyle.NONE) for text positioned side-by-side

### Alignment:
- Preserve original text alignment
- Left, center, right, or justified
- Use `alignment: AlignmentType.LEFT/CENTER/RIGHT/JUSTIFIED`

## IMPLEMENTATION WORKFLOW:

### Step 1: Initial Scan
- Read entire PDF content
- Identify page breaks
- Note document type (letter, essay, report, etc.)
- Mark headers/footers to skip

### Step 2: Content Classification
- Note EXACT font sizes from PDF (do NOT interpret as "titles" or "headings")
- Separate into paragraphs
- Note formatting (bold, italic, exact sizes)
- Identify spatial layout: text positioned horizontally side-by-side
- Find handwritten signatures to replace
- Identify lists (bulleted or numbered)

### Step 3: Build Structure
- Create document outline
- Reproduce exact font sizes from PDF (no special "title" or "heading" styles)
- Ensure all styles have `color: "000000"`
- Plan paragraph spacing
- Plan invisible tables for horizontal spatial layouts

### Step 4: Implement Page Markers
**REMINDER:** Use the actual PDF page position (1st page, 2nd page, 3rd page of the PDF file), NOT any page numbers written in the document content.

For PDF page 2 and onwards, start with:
```javascript
new Paragraph({
  children: [new TextRun({ text: "[Page 2 of the original]", color: "000000" })],
  spacing: { after: 240 }
})
```
For PDF page 3:
```javascript
new Paragraph({
  children: [new TextRun({ text: "[Page 3 of the original]", color: "000000" })],
  spacing: { after: 240 }
})
```
And so on for each subsequent PDF page.

### Step 5: Implement Text
- Create paragraphs with proper formatting
- Apply styles (bold, italic, alignment)
- ALWAYS set `color: "000000"` on every TextRun
- Add spacing before/after elements
- Insert page breaks where needed
- Replace signature images with [Signature] text

### Step 6: Quality Check
- Verify all content extracted (except headers/footers)
- Confirm ALL text is black
- Confirm page markers on pages 2+
- Confirm signatures replaced with [Signature]
- Ensure professional appearance
- Verify no tables were created

### Step 7: Export
- Save with NO metadata in Document properties
- Verify file is valid .docx format

## CODE IMPLEMENTATION:

### Required Imports:
```javascript
const fs = require('fs');
const { Document, Packer, Paragraph, TextRun, Table, TableRow, TableCell,
        AlignmentType, BorderStyle, UnderlineType, PageBreak } = require('docx');
// Note: Table imports added for invisible tables (spatial layout only)
```

### Document Template with NO METADATA:
```javascript
const doc = new Document({
  // CRITICAL: Empty metadata
  creator: "",
  description: "",
  title: "",
  subject: "",
  keywords: "",
  lastModifiedBy: "",
  revision: "",

  // Default styles - BLACK TEXT ONLY
  styles: {
    default: {
      document: {
        run: {
          font: "Arial",
          size: 22, // 11pt default
          color: "000000" // BLACK ALWAYS
        }
      }
    }
  },

  sections: [{
    properties: {
      page: {
        margin: { top: 1440, right: 1440, bottom: 1440, left: 1440 }
      }
    },
    children: [
      // Page 1 content - NO page marker
      // ... content ...

      new Paragraph({ children: [new PageBreak()] }),

      // Page 2 - START with page marker
      new Paragraph({
        children: [new TextRun({ text: "[Page 2 of the original]", color: "000000" })],
        spacing: { after: 240 }
      }),
      // ... page 2 content ...
    ]
  }]
});
```

### Text Paragraph Template:
```javascript
new Paragraph({
  alignment: AlignmentType.LEFT,
  spacing: { before: 120, after: 120 },
  indent: { left: 0, right: 0 },
  children: [
    new TextRun({
      text: "Content here",
      bold: false,
      italics: false,
      size: 22, // 11pt
      color: "000000" // ALWAYS BLACK
    })
  ]
})
```

### Signature Replacement:
```javascript
// When you encounter a signature image:
new Paragraph({
  children: [new TextRun({
    text: "[Signature]",
    color: "000000"
  })]
})
```

### List Example:
```javascript
// For bulleted/numbered lists, use appropriate paragraph formatting
new Paragraph({
  bullet: { level: 0 }, // or use numbering
  children: [new TextRun({
    text: "List item text",
    color: "000000"
  })]
})
```

### Invisible Table for Spatial Layout:
```javascript
// For text positioned side-by-side (e.g., Name left, Date right)
const { Table, TableRow, TableCell, BorderStyle } = require('docx');

const noBorder = { style: BorderStyle.NONE, size: 0, color: "FFFFFF" };
const noBorders = { top: noBorder, bottom: noBorder, left: noBorder, right: noBorder };

new Table({
  columnWidths: [4680, 4680], // Adjust as needed
  margins: { top: 0, bottom: 0, left: 0, right: 0 },
  rows: [
    new TableRow({
      children: [
        new TableCell({
          borders: noBorders,
          children: [new Paragraph({
            alignment: AlignmentType.LEFT,
            children: [new TextRun({ text: "Left text", color: "000000" })]
          })]
        }),
        new TableCell({
          borders: noBorders,
          children: [new Paragraph({
            alignment: AlignmentType.RIGHT,
            children: [new TextRun({ text: "Right text", color: "000000" })]
          })]
        })
      ]
    })
  ]
})
```
