# 🇬🇧 ENGLISH: Step-by-Step Guide

## 1️⃣ Download the App
1.  Go to the GitHub page (where you likely found this).
2.  Click the green **"Code"** button.
3.  Select **"Download ZIP"**.
4.  Find the ZIP file in your "Downloads" folder and **Unzip it** (double-click it).
    *   *You will now have a folder named `Claude-PDF-to-Word-converter`.*

## 2️⃣ First Time Setup (Do this ONCE)
Before you can convert files, you need a "key" to pay for the AI.
1.  Go to **[console.anthropic.com](https://console.anthropic.com/)**.
2.  Create an account and log in.
3.  You must add credits (minimum $5). This is very cheap and lasts for hundreds of pages.
4.  Click **"Get API Keys"** or **"API Keys"** in the menu.
5.  Click **"Create Key"**.
6.  Copy the key (it looks like `sk-ant-xxxxxxxx...`). **Save this for Step 4.**

## 3️⃣ How to Open the App
You do not need to install anything. You just "run" a file.

### 🍎 For Mac Users
1.  Open the `Claude-PDF-to-Word-converter` folder.
2.  Look for the file: **`start_app.command`**.
3.  **Double-click it.**
    *   *⚠️ If Mac says "Unidentified Developer"*: Right-click the file > Select **Open** > Click **Open** again.
4.  A **black window** (Terminal) will appear. **Keep this open!**
5.  Your web browser (Chrome/Safari) will automatically open the app.

### 🪟 For Windows Users
1.  Open the `Claude-PDF-to-Word-converter` folder.
2.  Look for the file: **`install_and_run.bat`**.
3.  **Double-click it.**
    *   *⚠️ If Windows says "Protected your PC"*: Click "More info" > "Run anyway".
4.  A **black window** will appear. **Keep this open!**
5.  Your web browser will automatically open the app.

### 💡 Pro Tip for Daily Use
*   **Mac**: Right-click `start_app.command` -> Select **"Make Alias"**. Drag the new Alias file to your Desktop. Now you can just click that icon on your Desktop!
*   **Windows**: Right-click `install_and_run.bat` -> **Send to** -> **Desktop (create shortcut)**. Now you have an icon on your Desktop.

## 4️⃣ Configure the App (First Run Only)
1.  In the app (in your browser), look at the top-right corner.
2.  Click the **Settings Icon (⚙️)**.
3.  Paste your **API Key** (from Step 2).
4.  Click **"Save"**.

## 5️⃣ How to Convert a PDF
1.  **Upload**: Drag your PDF file into the big box that says "Click to upload".
2.  **Choose Intelligence**:
    *   **Haiku**: Fast & Cheap (Best for simple text).
    *   **Sonnet**: Smart (Best for tables, handwriting, complex layouts).
    *   **Opus**: Genius (Best for very hard documents).
3.  **Convert**: Click the purple **"Convert to Word"** button.
4.  **Wait**: You will see a progress bar.
    *   *Note: It might take 1-2 minutes. The AI is reading every word!*
5.  **Download**: When it reaches 100%, click **"Download DOCX"**.

# 🇪🇸 ESPAÑOL: Guía Paso a Paso

## 1️⃣ Descargar la Aplicación
1.  Vaya a la página de GitHub (donde probablemente encontró esto).
2.  Haga clic en el botón verde que dice **"Code"**.
3.  Seleccione **"Download ZIP"**.
4.  Busque el archivo ZIP en su carpeta de "Descargas" y **Descomprímalo** (doble clic).
    *   *Ahora tendrá una carpeta llamada `Claude-PDF-to-Word-converter`.*

## 2️⃣ Configuración Inicial (Solo una vez)
Antes de convertir archivos, necesita una "llave" (Key) para pagar por la Inteligencia Artificial.
1.  Vaya a **[console.anthropic.com](https://console.anthropic.com/)**.
2.  Cree una cuenta e inicie sesión.
3.  Debe agregar créditos (mínimo $5 USD). Es muy barato y le durará para cientos de páginas.
4.  Haga clic en **"Get API Keys"** o **"API Keys"** en el menú.
5.  Haga clic en **"Create Key"**.
6.  Copie la llave (se ve como `sk-ant-xxxxxxxx...`). **Guárdela para el Paso 4.**

## 3️⃣ Cómo Abrir la Aplicación
No necesita instalar nada. Solo debe "ejecutar" un archivo.

### 🍎 Para Usuarios de Mac
1.  Abra la carpeta `Claude-PDF-to-Word-converter`.
2.  Busque el archivo: **`start_app.command`**.
3.  **Haga doble clic en él.**
    *   *⚠️ Si Mac dice "Desarrollador no identificado"*: Haga clic derecho en el archivo > Seleccione **Abrir** > Haga clic en **Abrir** otra vez.
4.  Aparecerá una **ventana negra** (Terminal). **¡Déjela abierta!**
5.  Su navegador web (Chrome/Safari) abrirá la aplicación automáticamente.

### 🪟 Para Usuarios de Windows
1.  Abra la carpeta `Claude-PDF-to-Word-converter`.
2.  Busque el archivo: **`install_and_run.bat`**.
3.  **Haga doble clic en él.**
    *   *⚠️ Si Windows dice "Protegió su PC"*: Haga clic en "Más información" > "Ejecutar de todas formas".
4.  Aparecerá una **ventana negra**. **¡Déjela abierta!**
5.  Su navegador web abrirá la aplicación automáticamente.

### 💡 Consejo Pro para Uso Diario
*   **Mac**: Clic derecho en `start_app.command` -> Seleccione **"Crear alias" (Make Alias)**. Arrastre el nuevo archivo Alias a su Escritorio. ¡Ahora solo necesita hacer clic en ese icono!
*   **Windows**: Clic derecho en `install_and_run.bat` -> **Enviar a** -> **Escritorio (crear acceso directo)**. Ahora tendrá un icono en su Escritorio.

## 4️⃣ Configurar la App (Solo la primera vez)
1.  En la aplicación (en su navegador), mire en la esquina superior derecha.
2.  Haga clic en el **Icono de Configuración (⚙️)**.
3.  Pegue su **API Key** (del Paso 2).
4.  Haga clic en **"Save"** (Guardar).

## 5️⃣ Cómo Convertir un PDF
1.  **Subir**: Arrastre su archivo PDF al cuadro grande que dice "Click to upload".
2.  **Elegir Inteligencia**:
    *   **Haiku**: Rápido y Barato (Mejor para texto simple).
    *   **Sonnet**: Inteligente (Mejor para tablas, escritura a mano, diseños complejos).
    *   **Opus**: Genio (Mejor para documentos muy difíciles).
3.  **Convertir**: Haga clic en el botón morado **"Convert to Word"**.
4.  **Esperar**: Verá una barra de progreso.
    *   *Nota: Puede tardar 1-2 minutos. ¡La IA está leyendo cada palabra!*
5.  **Descargar**: Cuando llegue al 100%, haga clic en **"Download DOCX"**.
