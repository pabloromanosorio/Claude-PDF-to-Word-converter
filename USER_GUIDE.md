# 🇬🇧 English Instructions

## 📥 How to Download (GitHub)
1.  **Go to the Repository**: Click the **"Code"** button (green) on the GitHub page.
2.  **Download**: Select **"Download ZIP"**.
3.  **Unzip**: Extract the downloaded file.
    *   *Note: The file size is approximately **320 MB**.*

## 🚀 Quick Start

### For Mac Users 🍎
1.  **Open the Folder**: Navigate to the folder containing this app.
2.  **Launch**: Double-click the file named **`start_app.command`**.
    *   *Tip: You can create a desktop shortcut! Right-click `start_app.command`, select **"Make Alias"**, and drag that new Alias file to your Desktop. Do NOT move the original file.*
3.  **First Run**: If you see a warning ("Unidentified Developer"):
    *   Right-click the file > Select **Open** > Click **Open** in the popup.
    *   (You only need to do this once).
4.  **Wait**: A black terminal window will open. Leave it open! Your web browser will launch automatically with the app.

### For Windows Users 🪟
1.  **Open the Folder**: Navigate to the folder containing this app.
2.  **Launch**: Double-click **`install_and_run.bat`**.
3.  **Wait**: A black window will appear. Leave it open! Your web browser will launch automatically.

---

## ⚙️ First Time Setup (One Time Only)
To use the AI, you need an API Key from Anthropic.
1.  **Get Key**: Go to [console.anthropic.com](https://console.anthropic.com/), sign up, and create an API Key (starts with `sk-ant-...`).
2.  **Enter Key**: In the app (in your browser), click the **Settings (⚙️)** icon in the top right.
3.  **Save**: Paste your key and click **Save**.

---

## 📝 How to Use
1.  **Upload**: Click the upload area or drag & drop your PDF/Image files.
2.  **Select Model**:
    *   **Haiku**: Fast & Cheap (Good for simple text).
    *   **Sonnet**: High Quality (Best for tables/handwriting).
    *   **Opus**: Maximum Intelligence (Best for very complex tasks).
3.  **Convert**: Click **"Convert to Word"**.
4.  **Monitor**: You can see real-time logs by clicking **"Show Logs"**.
5.  **Download**: Once finished, click **"Download DOCX"**.

---

## ❓ Troubleshooting
*   **Browser didn't open?** Go to `http://localhost:3000` in Chrome/Safari.
*   **Conversion failed?** Check the "Show Logs" section for details.
*   **"EADDRINUSE" error?** Restart your computer or close other terminal windows.

# 🇪🇸 Instrucciones en Español

## 📥 Cómo Descargar (GitHub)
1.  **Ir al Repositorio**: Haga clic en el botón **"Code"** (verde) en la página de GitHub.
2.  **Descargar**: Seleccione **"Download ZIP"**.
3.  **Descomprimir**: Extraiga el archivo descargado.
    *   *Nota: El tamaño del archivo es de aproximadamente **320 MB**.*

## 🚀 Inicio Rápido

### Para Usuarios de Mac 🍎
1.  **Abrir la Carpeta**: Navegue a la carpeta que contiene esta aplicación.
2.  **Iniciar**: Haga doble clic en el archivo llamado **`start_app.command`**.
    *   *Consejo: ¡Puede crear un acceso directo! Haga clic derecho en `start_app.command`, seleccione **"Crear alias" (Make Alias)**, y arrastre ese nuevo archivo al Escritorio. NO mueva el archivo original.*
3.  **Primera Vez**: Si ve una advertencia ("Desarrollador no identificado"):
    *   Haga clic derecho en el archivo > Seleccione **Abrir** > Haga clic en **Abrir** en la ventana emergente.
4.  **Esperar**: Se abrirá una ventana negra (terminal). ¡Déjela abierta! Su navegador web se abrirá automáticamente con la aplicación.

### Para Usuarios de Windows 🪟
1.  **Abrir la Carpeta**: Navegue a la carpeta que contiene esta aplicación.
2.  **Iniciar**: Haga doble clic en **`install_and_run.bat`**.
3.  **Esperar**: Aparecerá una ventana negra. ¡Déjela abierta! Su navegador web se abrirá automáticamente.

---

## ⚙️ Configuración Inicial (Solo una vez)
Para usar la IA, necesita una "API Key" (Clave API) de Anthropic.
1.  **Obtener Clave**: Vaya a [console.anthropic.com](https://console.anthropic.com/), regístrese y cree una API Key (empieza por `sk-ant-...`).
2.  **Ingresar Clave**: En la aplicación (en su navegador), haga clic en el icono de **Configuración (⚙️)** arriba a la derecha.
3.  **Guardar**: Pegue su clave y haga clic en **Save API Key**.

---

## 📝 Cómo Usar
1.  **Subir**: Haga clic en el área de carga o arrastre sus archivos PDF/Imagen.
2.  **Seleccionar Modelo**:
    *   **Haiku**: Rápido y Económico (Bueno para texto simple).
    *   **Sonnet**: Alta Calidad (Mejor para tablas/escritura a mano).
    *   **Opus**: Máxima Inteligencia (Para tareas muy complejas).
3.  **Convertir**: Haga clic en **"Convert to Word"**.
4.  **Monitorizar**: Puede ver los registros en tiempo real haciendo clic en **"Show Logs"**.
5.  **Descargar**: Al finalizar, haga clic en **"Download DOCX"**.

---

## ❓ Solución de Problemas
*   **¿No se abrió el navegador?** Vaya a `http://localhost:3000` en Chrome/Safari.
*   **¿Falló la conversión?** Revise la sección "Show Logs" para ver detalles.
*   **¿Error "EADDRINUSE"?** Reinicie su computadora o cierre otras ventanas de terminal.
