# 📄 PDF to Word Converter (Easy Version)

Welcome! This tool helps you convert PDF files (and images) into editable Word documents using advanced AI. It's designed to be super simple to use.

## 🚀 How to Start the App

You don't need to be a computer expert to run this. Just follow these steps:

1.  **Find the Launcher**: Look for the file named **`start_app.command`** in this folder.
2.  **Double-Click It**:
    *   A black window (Terminal) will pop up. **Do not close this window!** It is the engine of the app.
    *   After a few seconds, your web browser (like Chrome or Safari) will automatically open to the converter page.
3.  **That's it!** You are ready to convert files.

> **Note**: If the browser doesn't open automatically, just open your browser and type `http://localhost:3000` in the address bar.

## 📝 How to Use

1.  **Upload a File**: Click the "Choose File" button and select your PDF or image.
2.  **Convert**: Click the big "Convert to Word" button.
3.  **Wait**: The AI is reading your document. This might take a minute or two depending on the size.
4.  **Download**: When it's done, a "Download Word Doc" button will appear. Click it to save your new file!

### ✨ Features
*   **Black Text Only**: The output will always use professional black text.
*   **Clean Tables**: No distracting background colors in tables.
*   **Standard Size**: Documents are automatically set to Letter size (8.5 x 11 inches).

## ❓ Troubleshooting

*   **"It says I need an API Key"**:
    *   Click the **Settings Icon (⚙️)** in the top right corner of the web page.
    *   Paste your Anthropic API Key. (If you don't have one, ask the person who gave you this software).
    *   Click "Save".

*   **"The black window closed and the app stopped"**:
    *   Just double-click `start_app.command` again to restart it.

*   **"I want to close the app"**:
    *   Simply close the black terminal window.

## 🔄 How to Update

If there are new features available, you can update the app easily:

1.  Double-click **`update_app.command`**.
2.  Wait for it to say "Update successful!".
3.  That's it! You have the latest version.
