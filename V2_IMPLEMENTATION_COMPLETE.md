## API Endpoints

### Conversion
- `POST /api/convert` - Upload and convert document
- `GET /api/jobs/{id}` - Get job status
- `GET /api/download/{id}` - Download result
- `WS /ws/jobs/{id}` - Real-time progress (WebSocket)

### Configuration
- `GET /api/settings` - Get default settings
- `POST /api/settings` - Save default settings
- `POST /api/api-key` - Save encrypted API key
- `GET /api/api-key/status` - Check if configured

### Statistics
- `GET /api/stats` - Usage statistics (30 days)
- `GET /api/storage` - Storage information
- `GET /api/health` - Health check

### Auto-Documentation
Visit `http://localhost:8000/docs` for interactive API docs (FastAPI auto-generated)

## Technical Highlights

### 1. Optimized Prompts

**Before (v1):**
```python
"""Convert this scanned document to professional Word (.docx) format.

## Document Settings
... 136 lines of verbose instructions ...
"""
# ~400 tokens
```

**After (v2):**
```python
"""Convert this document to Word (.docx) format.
**Output Settings:** Font: Arial 12pt, Margins: 1.0"
**Text Extraction:** Extract all text exactly as shown.
**Table Handling (CRITICAL):** Preserve exact structure, merged cells.
**Generate Document:** Use docx skill."""
# ~120 tokens (70% reduction)
```

### 2. Multi-Strategy File Extraction

```python
# v1: Single brittle approach
file_ids.append(item.content.content.file_id)  # Crashes on API change

# v2: 4 fallback strategies
strategies = [
    extract_from_bash_result,      # Primary
    extract_from_text_patterns,     # Fallback 1
    extract_from_metadata,          # Fallback 2
    extract_from_content_inspection # Last resort
]
# Won't break on API changes!
```

### 3. Comprehensive Retry Logic

```python
# v1: Only 2 error codes
if error_code in [429, 529]:
    retry()

# v2: 6 error codes + network errors
retryable = {429, 500, 502, 503, 504, 529}
# + Exponential backoff with jitter
# + Special rate limit handling
# + Network timeout retries
```

### 4. Real-Time WebSocket Progress

```javascript
// Frontend connects to WebSocket
ws = new WebSocket('/ws/jobs/{job_id}');

ws.onmessage = (event) => {
    const update = JSON.parse(event.data);
    // { progress: 67, step: "Processing page 10 of 15..." }
    updateProgressBar(update.progress);
    updateStatusText(update.step);
};
```

## Troubleshooting

### "API key not configured"
**Solution:** Enter API key in web UI or set in .env file

### "Connection refused"
**Solution:** Make sure server is running:
```bash
cd v2
./start.sh
```

### "File too large"
**Solution:** Maximum file size is 50MB. Use page range selection for larger files.

### WebSocket not connecting
**Solution:**
1. Check browser console for errors
2. Refresh the page
3. Ensure no firewall blocking WebSocket

### Database issues
**Solution:** Reset database (will lose history):
```bash
rm ~/.pdf-converter/converter_v2.db
# Restart server
```
